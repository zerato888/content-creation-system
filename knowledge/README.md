## Playbooks (manuales de un rol, de punta a punta)
Ciclo completo: escuchar, idear, guionar, visualizar, reutilizar, vender y medir; la guardiana de voz corre en el medio.
| Playbook | Cuándo leerlo |
|---|---|
| [playbooks/investigador-de-audiencia.md](playbooks/investigador-de-audiencia.md) | Antes de idear: encontrar la tensión y el lenguaje real de la audiencia |
| [playbooks/ideacion-de-contenido.md](playbooks/ideacion-de-contenido.md) | Para armar un banco de ideas priorizado |
| [playbooks/guionista.md](playbooks/guionista.md) | Al escribir un reel, un video largo o un carrusel |
| [playbooks/narrador-visual.md](playbooks/narrador-visual.md) | Al traducir un guion a un plan visual y prompts |
| [playbooks/guardian-de-voz.md](playbooks/guardian-de-voz.md) | Para extraer la voz de una persona y revisar textos contra ella |
| [playbooks/reutilizador-de-contenido.md](playbooks/reutilizador-de-contenido.md) | Para sacar de una pieza de diez a quince salidas nativas |
| [playbooks/escritor-de-oferta-y-bio.md](playbooks/escritor-de-oferta-y-bio.md) | Al escribir bio, página de enlace, página de venta o mensajes directos |
| [playbooks/analista-de-resultados.md](playbooks/analista-de-resultados.md) | Al leer métricas y decidir el próximo paso |
