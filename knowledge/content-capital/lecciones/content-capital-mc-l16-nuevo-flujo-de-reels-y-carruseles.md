## En una línea

Plantilla importable del flujo de comentarios en reels/carruseles tras las nuevas reglas de Meta (hay que entregar el recurso prometido): respuestas públicas aleatorias, etiquetas de formato/ángulo/fecha, asignación, trifurcación por ángulo con aleatorizador de recursos, botón que entrega el recurso una sola vez, y bifurcación a dos flows centrales ("general" para no seteados con la pregunta A/B, "seteando" para ya seteados con preguntas de seguimiento). Instructor: **Paolo** (inferencia: mismo Loom y webcam que L15/L17).

## Recorrido de la clase

|---|---|

| 03:55 | Tras el botón hay input del lead → se pueden hacer seguimientos; con recopilación de datos se miden respuestas. |

| 06:51 | Para cada pieza nueva: duplicar el flow y cambiar pieza y etiquetas. |

| 09:45 | Marcar como abierta; asignación a grupo de setters (o aleatorizador entre setters) si no tiene ASIGNADO. |
| 10:33 | Trifurcación por ángulo: ManyChat, follow-me ads y genérico ("cualquier valor"). Ejemplo coach fitness: hormonas / tonificar. |
| 12:37 | Cada rama: aleatorizador de recursos de ese ángulo; genérico = guías, biblioteca de recursos. |
| 13:51 | Condición + campo para que nadie reciba dos veces el mismo recurso. |
| 14:24 | Mensaje: "buenas, vi tu comentario, te regalo el acceso a una clase de Many muy completa, sin vueltas tocá el botón". |
| 14:51 | Etiqueta por botón ("botón recurso many 1, 2…") + condición para que el mensaje llegue una sola vez aunque toquen el botón muchas veces (anti-spam). |
| 15:59 | El recurso se envía dentro del chat, no como link directo de salida, para que vuelvan a responder. |
| 16:44 | Sin recursos por ángulo: biblioteca general en varios documentos "de diferentes colores" para más variantes. |
| 18:08 | Perspectiva de setting: un lead ya seteado no debe recibir la pregunta de arranque. Etiqueta **SETEANDO** en todas las preguntas y pasos de la estructura de prospección (incluido el pitch de calendario). |

| 23:22 | Seteando: preguntas de seguimiento que no choquen con la estructura ("¿cómo vienen los leads que te están llegando?", "che, me parece que ya habíamos hablado", "¿cuál viene siendo tu principal problema para sacar clientes?"). |
| 25:28 | Versión sin ángulos: igual pero sin trifurcación, con recursos genéricos. |
| 26:35 | Proceso: importar el flow, dejar condiciones, cambiar comunicación y recursos; en "seteando", 2-4 preguntas de seguimiento propias. |
