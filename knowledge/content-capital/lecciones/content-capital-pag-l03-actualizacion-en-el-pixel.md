## En una línea

Ajuste corto al píxel para tener más datos y menos eventos duplicados: **extender la subida de atribuciones a 90 días**, crear una **lista de dominios autorizados** (solo tu dominio verificado puede mandar eventos), verificar el dominio en Seguridad de marca y vincularlo a la fanpage.

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:00 | Actualización necesaria: hay muchos eventos duplicados y datos que llegan de muchos lugares. |
| 00:26 | Objetivo: rastrear mejor los eventos y que solo tu dominio registrado mande datos. |
| 00:34 | Ruta: Orígenes de datos → Conjuntos de datos → el píxel → Configuración. |
| 01:01 | **Extender subidas de atribuciones**: permite atribuir impresiones de hace 90 días. |

| 02:05 | Crear la lista, elegir el dominio y confirmar. |
| 02:19 | Si no tenés dominio: Configuración → Seguridad de marca → Dominios → Agregar la URL de la home (el ".com"). |

| 03:01 | Asignar activos: vincular el dominio a la fanpage. |
