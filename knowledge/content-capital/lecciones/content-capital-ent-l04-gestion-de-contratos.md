## En una línea

Tutorial para cargar la plantilla de contrato en **PandaDoc** y mandarla a clientes: subir el contrato en formato .doc, crear el rol propio y el del cliente, reemplazar datos fijos por **variables** (fecha, nombre, email, empresa), arrastrar los campos de **firma**, iniciales y casillas, y enviarlo a mano o automáticamente con **Zapier** después de un formulario. La firma propia puede ir precargada como imagen para no firmar cada contrato.

Instructor: **"Juani"** (00:05, "de acá los saluda Juani"). No dice apellido. Es probablemente el "Juan" que recibe los datos de clientes nuevos en L3 03:45 (inferencia). Distinto del instructor de L2-L3.

> **No es asesoría legal.** La clase es solo sobre la herramienta; no habla del contenido del contrato.

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:16 | Objetivo: cargar la plantilla de contrato en PandaDoc, el software que usan para mandar contratos. |
| 00:28 | Ventaja frente a otros que probaron: se conecta con **Zapier** y puede mandar el contrato automáticamente, por ejemplo después de que el cliente completa un formulario. Ahorra trabajo administrativo y tiempo. |
| 00:59 | La automatización con Zapier se ve en el video de onboarding; esta clase es el paso previo. |
| 01:18 | Tres planes: el más barato no conecta con Zapier pero sirve para mandar a mano; ellos usan el **intermedio**, que sí conecta. No pagar más si solo mandás a mano. |
| 01:47 | Paso 1: crear cuenta → Documentos → Plantillas → Nueva plantilla. |
| 02:00 | Subir el archivo en **formato .doc** (Word o Google Docs exportado): lo convierte mucho mejor que un PDF o una imagen. Después de la conversión puede haber que acomodar algunas cosas. |
| 02:57 | Paso 2: crear un **rol** propio (tu nombre o el de tu empresa). El rol del cliente viene por defecto. |
| 03:22 | Paso 3: **variables de sistema**, por ejemplo la fecha del documento o la fecha de envío, para que se completen solas. |
| 04:06 | **Variables del cliente**: nombre, apellido, email, empresa y más. Se completan automáticamente. |
| 04:31 | Paso 4: arrastrar el campo de **firma** del cliente al lugar correcto. Opcional: **iniciales** en un artículo puntual para que lo firme aparte, y **casillas** de check. |
| 05:16 | Paso 5, envío: usar la plantilla, cargar nombre y email del destinatario y los campos de las variables. |
| 05:54 | Si se automatiza con Zapier, el formulario previo tiene que **preguntar esos datos**: PandaDoc no inventa la variable, la saca de algún lado. |
| 06:21 | Se genera el documento a partir de la plantilla, ya completo con los datos del cliente. Se manda por correo con un mensaje opcional. |
| 07:19 | PandaDoc muestra el estado: **visto** cuando lo abrió sin firmar y **completado** cuando firmó. Puede notificar por mail. |
| 07:44 | **Firma propia precargada**: dibujarla o escribirla, sacarle una captura y subirla como imagen al contrato. Así sale firmado por vos. La alternativa es un campo de firma propio, que obliga a firmar cada contrato. |
| 08:58 | Con eso ya se pueden mandar todos los contratos desde PandaDoc. |
