## En una línea

Para encontrar expertos a prospectar se busca una cuenta del nicho, se abren con Ctrl+clic las **cuentas sugeridas** relacionadas y se responde una historia (o una destacada) con un "hola, quería consultar algo" que **varía una palabra en cada envío**; una cuenta de prospección = un solo nicho.

Instructor: no se presenta. Por voz y estilo es **Alan Correa** (inferencia).

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:00 | Cómo buscar cuentas para prospectar. Se entra a un nicho elegido (ejemplo: trading) y se abre un creador verificado con muchos seguidores. |
| 00:35 | El botón de sugeridos muestra cuentas relacionadas; se abren en pestañas con **Ctrl+clic**. |
| 00:46 | Preferir cuentas verificadas con bastantes seguidores, aunque también sirven las que están arrancando: con este volumen "vamos a tener para elegir". |
| 01:04 | **Responder una historia**; si no tiene, responder una historia destacada. Mensaje: "Hola, quería consultar algo". |
| 01:31 | Criterio rápido de calificación: seguidores, que trabaje en el tema, perfil ordenado, que cree contenido. |
| 01:42 | **Cambiar alguna palabra** en cada mensaje ("quería hacer una consulta") para que Instagram no detecte spam por texto repetido. |
| 02:07 | 50 mensajes por día por cuenta una vez calentada ([[content-capital-sho-l08-sistema-de-adquisicion]]). |
| 02:13 | **Una cuenta, un nicho**: una cuenta solo para trading, otra para coaches, etc., para que las cuentas no se pisen entre sí. |
