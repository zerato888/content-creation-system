## En una línea

Introducción a la publicidad paga en Meta: qué hace (y qué no) un *trafficker*, por qué se anuncia desde el **Administrador comercial** y no con el botón "Promocionar", cómo se arma la base (fanpage → Instagram/WhatsApp vinculados → portfolio comercial → cuenta publicitaria → pago → 2FA), qué políticas de Meta provocan baneos, y un glosario de métricas y conceptos. Instructor: **Nicolás Donovan**, coach de anuncios del "Club de negocios" (00:00), no Ramiro ni Mati.

| 00:45 | Meta Ads "parece chino" pero es más fácil de lo que parece. Objetivo: poder pensar la situación y accionar bien. |
| 01:13 | Meta Ads sirve para llegar a las personas correctas, en el momento correcto, con el anuncio correcto. |
| 01:34 | **Trafficker**: especialista en correr anuncios con estrategia y segmentación para maximizar ventas o clientes. |
| 01:49 | Qué SÍ hace: configurar fanpage y Administrador comercial, crear y optimizar campañas, reportes, asesorar contenido y copies. |
| 02:06 | Qué NO hace: crear contenido, gestionar redes, contestar mensajes, editar creativos. |
| 02:19 | No es que no puedas hacerlo: es para marcar límites y que el cliente no tenga expectativas falsas. Contenido + anuncios = servicio integral. |
| 03:39 | Dos formas de anunciar: botón **Promocionar** o **Administrador comercial** (recomendado). |
| 03:56 | Promocionar: simple pero la forma menos efectiva y más cara. Solo intereses, sin comportamientos, sin elegir objetivo ni testear conjuntos. |
| 04:27 | Solo lo recomienda para ganar seguidores (acción "Visitar perfil"). Trae volumen pero seguidores de baja calidad. |
| 05:32 | Administrador comercial: el recomendado para tráfico, captación de leads y ventas. |
| 05:56 | Qué es el Administrador comercial (Business Manager): gestiona activos (páginas, Instagram, píxeles, públicos, catálogos, anuncios) y permite sumar socios o agencias. |
| 06:51 | Requisitos: Facebook personal, página donde seas administrador, Instagram conectado (opcional pero recomendado). |
| 07:16 | Crear la página con información real y completa: Meta la usa para validar identidad y evitar baneos. |
| 08:43 | Demo: crea la página "CDN - TESTING", categoría agencia de publicidad. |
| 10:08 | Completar sitio web, teléfono, mail, ubicación, horarios, foto de perfil y portada. Sin eso, "difícil que te compre" alguien. |
| 10:45 | Vincular un **WhatsApp Business** (no el personal; si no, no deja vincularlo). |
| 11:08 | Panel para profesionales → Configuración → Cuentas vinculadas: conectar WhatsApp (código por mensaje) e Instagram profesional. |
| 13:44 | La cuenta publicitaria personal que abre por defecto no sirve: tiene menos beneficios que una de negocio. |
| 14:41 | Crear un **portfolio comercial** con nombre del negocio, tu nombre y mail. Hay un límite de portfolios por persona (a él le da error). |
| 15:48 | Entrar a la configuración desde business.facebook.com → abajo → Administrador comercial. **Evitar Meta Business Suite**: "funciona muy pero muy mal". |
| 16:45 | Cómo distinguirlos: la pestaña dice "Meta Business Suite" o "Configuración del negocio". |
| 17:27 | Activos: personas, páginas, cuentas publicitarias, Instagram, WhatsApp, conjuntos de datos, dominios, facturación y pagos. |

| 18:22 | Personas: como mínimo tu perfil. Invitar socios por mail; cuidado con dar **control total** (puede borrar el portfolio y administrar finanzas/tarjetas). |
| 20:12 | Demo: acepta la invitación desde el mail. Verificar que figure tu nombre y tu mail; si no, "¿No eres X?". |
| 22:12 | Páginas → Agregar. Si falla, otro negocio ya tiene tu página y hay que pedirle que la desvincule. |
| 23:19 | Cuentas publicitarias → Agregar → crear con nombre, zona horaria y divisa (igual a la del medio de pago). |
| 23:47 | Meta ya casi no da cuentas nuevas: "cuiden la como oro". Info completa, nada baneable, tarjetas bien configuradas. |
| 24:28 | Demo: cuenta "CDN TEST 1", Argentina/Buenos Aires, peso argentino. Asignarse todos los permisos (control total). |
| 26:03 | País, divisa y zona horaria **no se pueden cambiar** después; el método de pago sí. |
| 27:48 | Cuentas de Instagram → conectar e iniciar sesión. Hay errores técnicos: "intentar, intentar, intentar", le pasa a todos. |
| 30:36 | Vincular la cuenta publicitaria al Instagram y asignar personas. En Activos conectados se ve la cuenta publicitaria. |
| 31:47 | Conjuntos de datos = píxel (queda para el módulo siguiente). Dominio = verificar la URL del negocio. |
| 32:39 | Píxel definido como "cámara de seguridad" que registra lo que hacen las personas en la web. |
| 33:06 | Repaso del resto de secciones de configuración (orígenes de datos, seguridad de marca, integraciones, pagos, centro de seguridad). |
| 34:20 | **Protip**: autenticación en dos pasos en la cuenta personal. Sin ella Meta "no te va a parar de perseguir" y puede banear. |
| 35:39 | Ruta: foto de perfil → Configuración y privacidad → Contraseña y seguridad → Autenticación en dos pasos → Google Authenticator (QR o clave). |
| 37:30 | Información del negocio: cargar lo máximo posible para que Meta verifique que es una empresa real. |
| 38:10 | **Políticas de Meta**: explotación de menores, actos delictivos, personas peligrosas, discriminación, odio. Infringirlas = cuenta irrecuperable. |
| 40:29 | Explotación de personas; productos ilegales según la región donde se pauta. |
| 41:34 | Información errónea desmentida por verificadores. |
| 41:59 | Fraudes: préstamos, empleo (promesas de dinero rápido, vacantes vagas, cobro por adelantado), apuestas, inversiones (retorno garantizado, esquema Ponzi, multiplicar dinero). |
| 44:45 | Prácticas engañosas y **sistemas para eludir la revisión** (cloaking): "no dura mucho tiempo". |
| 45:43 | Alcohol y salud/bienestar solo a mayores de 18; nada de autopercepción negativa ni cuerpo ideal. |
| 46:30 | Financieros y seguros: +18, sin pedir datos personales, con autorización regulatoria. Cripto: requiere permiso previo por escrito. |
| 47:37 | Revisar las políticas al crear los creativos: evita baneos propios y del cliente. |
| 48:15 | **Glosario**: Administrador comercial, usuario, página, cuenta publicitaria, catálogo. |
| 49:45 | Píxel, dominio, **API de conversiones** (conexión directa web–Meta). |
| 50:44 | La API existe porque Apple dejó elegir no ser rastreado por el píxel; recupera eventos de usuarios de Apple. |
| 51:26 | Segmentación; **alcance** (personas únicas, distinto de impresiones). |
| 52:07 | **Costo por resultado**: ejemplo 10 USD gastados / 2 ventas = 5 USD por venta. |
| 53:07 | **CTR** = "la métrica de la persuasión". Por debajo de 2,5-3 % el anuncio no persuade. |
| 53:54 | **ROAS**: ventas generadas / gasto en publicidad. |
| 54:22 | Públicos: **personalizados** (ya interactuaron, "tibios", para retargeting), **guardados** (reutilizar configuración), **similares** (lookalike). |
| 55:53 | Ejemplo: personalizado = quienes interactuaron con tu Instagram en 180 días; similar = gente parecida a ese grupo. |
| 56:58 | **CPC**: costo por clic. |
| 57:18 | **Público de calidad**: segmentar para subir probabilidad de venta (camiseta de Boca a hinchas de Boca, no de River). |
| 58:05 | **Conversiones**: acciones valiosas; en un embudo a VSL, agendar la llamada. |
| 58:43 | Campaña (objetivo: uno solo) → conjunto (público, presupuesto, ubicación) → anuncio (creativo). |
| 59:40 | Ubicaciones: Facebook e Instagram siempre; Messenger sí; **Audience Network** (juegos de celular) no, porque ensucia métricas. |
| 60:17 | Anuncio, intereses, **impresiones** (10 personas de alcance pueden ser 30 impresiones). |
| 61:15 | Visitas a la página de destino. |
| 61:39 | Cierre: el mejor trafficker no sigue un solo camino, es el más creativo. Sacarse el miedo a probar, con sentido común. |

## Tareas y herramientas

- Crear fanpage con datos reales, vincular Instagram profesional y WhatsApp Business.
- Crear portfolio comercial y cuenta publicitaria de negocio (definir país, divisa y zona horaria de una vez), cargar método de pago.
- Activar autenticación en dos pasos (Google Authenticator).
- Leer las políticas publicitarias de Meta antes de crear creativos.
- Herramientas: Administrador comercial (business.facebook.com), Administrador de anuncios, Google Authenticator. Documento guía propio del instructor (Google Doc).
