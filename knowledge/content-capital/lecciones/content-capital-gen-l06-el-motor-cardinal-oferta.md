## En una línea

Clase teórica (Mati Molina la presenta al inicio, 00:05) sobre la psicología de la oferta. Un extraño se vuelve cliente por **6 pilares** (impulso → meta → problema → dolor → acción → confianza). El vendedor solo controla dos: amplificar el dolor y crear confianza. Se suman el **umbral de acción**, la **brecha**, los 7 componentes de la oferta, los tipos (mínima viable, Grand Slam, modular, productizada), las estructuras (escalera, cebolla, única), la **oferta espejo**, la filosofía de precios y el "arte de resonar" con las **condiciones latentes**.

| 07:38 | "Regla 1: enfocarte en los 6 pilares. Regla 2: no olvidarte de la regla 1." |
| 08:36 | La cadena: el impulso crea una meta, la meta un problema, el problema un dolor, el dolor una acción, y la acción requiere confianza. |
| 09:15 | Qué depende de quién: el extraño trae impulso, meta, problema, dolor y acción. Tu tarea es **crear confianza** y **amplificar el dolor**. |
| 10:38 | El dolor de quedarse tiene que ser mayor que el dolor de actuar. Dos reglas: no podés crear dolor (lo exponés y amplificás) ni crear acción (la provocás con emociones). |
| 11:35 | Crédito a Charlie Morgan, "mi mentor": enfocarse en lo controlable. |
| 11:55 | **3 fuentes de confianza**: 1) la oferta (ejemplo del coach de tenis: de "rendir mejor" a "te ayudo a ganarle al que nunca le ganaste"); 2) vos y tu convicción genuina (12:48); 3) tus clientes, con testimonios y casos (13:16). |
| 13:43 | No importa cuál uses, sí que consigas la confianza. "El 80% del apalancamiento lo tiene tu oferta" (14:07). |
| 14:16 | **5 fuentes de dolor**: problemas (conscientes), necesidades no cubiertas, tener algo indeseado, querer lo que no tengo (inconscientes) y consecuencias (conscientes). |
| 16:46 | Para sacar dolor, hacé énfasis en los problemas y en las consecuencias: son las fuentes conscientes. La gente culpa a esas fuentes del dolor que traen las inconscientes. |
| 17:27 | Amplificá el dolor de forma **indirecta**. No "sos pobre", sino "dejá de hacer este embudo / esta dieta / estas apps de citas". Apuntá a la raíz, no a la consecuencia. |
| 18:18 | **4 formas indirectas**: preguntas (ejemplo de la clínica: "¿cuántas consultas por día?" → "unas 10 por semana"), explorar problemas, discutir consecuencias y crear seriedad. |
| 19:40 | Preguntas modelo para ventas, marketing y anuncios. |
| 20:15 | Objeción ética: es como el médico, un dolor temporal para aliviar uno permanente. |
| 20:53 | **Umbral de acción**: cada persona tiene uno propio. Los motores son el dolor y la confianza. |
| 21:38 | Ecuación ilustrativa: (%dolor + %confianza) / 2 = chance de actuar. Ejemplo: 50% y 75% dan 62,5%. Quien está justo debajo del umbral necesita "un pequeño empujón". |
| 22:32 | Gráfico: dudas y comodidad contra dolor y confianza. Hay un punto de quiebre. Invertir las emociones: remover dudas = confianza, remover comodidad = dolor (23:21). |
| 23:41 | **La brecha (the gap)**: situación actual → situación deseada en los mercados eternos (salud, dinero, relaciones, felicidad). Todos los días la gente compra para cruzarla. |
| 24:39 | Posicionate como la escalera o el puente que cruza la brecha. |
| 25:03 | **Teoría de ofertas**: la oferta es cómo se empaqueta y posiciona el producto. Su fuerza es relativa a la competencia; decide el mercado. |
| 26:13 | Ejemplo débil vs. fuerte: "curso para tener más clientes con Instagram" vs. "sistema listo para aplicar, solo reels e historias, con acompañamiento de experto". |
| 26:50 | "El 90% en redes no sabe nada de creación de ofertas": ventaja asimétrica. |
| 27:00 | Aplica sobre todo a high ticket. La oferta inspira confianza y es el vehículo para escapar (ejemplo: 20k/mes solo con reels e historias). |
| 27:52 | Única y distinta: "los nichos no se saturan, la oferta sí". Ejemplo fitness: "10 kilos en 3 meses" quemado vs. "glúteos en 90 días sin gimnasio". |
| 28:29 | **Lo que NO es una oferta**: producto, servicio, garantía, descuento, precio. Son elementos que se empaquetan. |
| 29:51 | **Poder de la oferta**: marea alta (el nicho es el bote, la oferta es el mar). Puede subir el cierre y el show rate hasta 50% y el agendamiento 5-10%. |
| 30:44 | Persuasión: con mejor oferta hace falta menos. Aprender a vender lleva años; a hacer ofertas, horas. |
| 31:30 | Empresas: una oferta tan buena "que se sientan estúpidos de decir que no" (cita de Hormozi). |
| 32:01 | Exponencial: débil 2¹, media 2³, fuerte 2⁹ = 512 (simbólico). Tocar solo la oferta les dio 3x-4x de facturación. |
| 32:49 | **Composición: 7 elementos**: resultado, tiempo, método, secretos, seguro, polarización, precio. Con ejemplos (33:30). |
| 34:28 | **3 niveles de presentación**: mensaje corto (3-5 palabras), mensaje largo y pitch. Ejemplo SYK: "transformamos tu conocimiento en un negocio millonario". |
| 35:37 | El pitch en llamada: el precio va primero, después el resultado, la metodología y los pilares. |
| 36:11 | Analogía política con la campaña de Milei 2023 (corto, largo, manifiesto). Aclara que no toma partido. |
| 36:54 | **Errores comunes**: 1) copiar y pegar (queremos "un mercado de uno"); se anuncia un GPT para crear la oferta en el módulo siguiente (37:38). |
| 37:50 | 2) Ir a la segura: cuanto más arriesgás, más confianza. El riesgo puede ser reputacional, temporal o de dinero. |
| 38:40 | 3) Complicarla: pensar como oferta mínima y quitar elementos. Ejemplo holístico: "recalibrar tu cerebro con neurociencia" no se entiende. |
| 39:39 | 4) Genérica: usar el vocabulario del nicho (en gimnasios "miembros", en dentistas "pacientes"; evitar "high ticket"). |
| 40:17 | 5) Basada en el producto: construí el producto alrededor de la oferta, no al revés. "Este error es fatal." |
| 40:59 | **Relación producto-oferta**: cuanto más difícil construir el producto, más fácil adquirir clientes. |
| 41:57 | Anécdota de dos mentores: USD 24k sin producto, sin resultados; USD 15k con un producto ultra trabajado (30 h de trabajo por cada hora de contenido), con resultados. |
| 43:30 | Regla 80/20: 80% del tiempo construyendo el producto, 20% contándolo. "Intercambiar dolor por confianza." |
| 45:12 | "Tu habilidad tiene que estar a la altura de tu oferta, no tu oferta a la altura de tus habilidades." |
| 45:39 | **Oferta mínima viable**: para quien no tiene experiencia en el nicho o sí en el nicho pero no en esa oferta. Enfoque "no hay nada que perder": comisión, por resultados o tarifa muy baja. |
| 47:00 | Ejemplos: contador (USD 300-500 por 3 meses a los primeros 4-5), agencia de leads por resultado, agencia de publicidad a comisión. Salir en 15 días a 3 meses como máximo. |
| 48:07 | **Oferta Grand Slam** (Hormozi): el 80% del resultado está en la oferta. Ecuación de valor: (resultado soñado × probabilidad) / (tiempo × esfuerzo). |
| 49:16 | "Un servicio no es una oferta" (vender community management o edición). |
| 49:33 | La gente compra resultados, pero el camino debe ser simple. La complejidad va al marketing y a los ángulos, no a la oferta. |
| 50:32 | **Específica y tangible**: cuantificable = un número; tangible = que se vea en esa situación ("quitarte los flotadores", "reemplazar el ingreso de tu trabajo"). |
| 51:48 | **Oferta modular**: para testear el mercado. Sirve para los primeros 5-10 clientes o hasta USD 3-5k/mes. Mantenerla traba en 5-6k/mes. |
| 54:14 | **Oferta productizada**: diferencias en nicho/avatar, precio fijo, proceso de ventas y entrega sistematizada. |
| 55:34 | Samsung (más de 20 modelos, modular) vs. Apple (4 iPhone, productizada). |
| 58:43 | "El peor error es quedarte en el infierno de las ofertas modulares." |
| 58:55 | **Estructuración**: por debajo de USD 15k/mes, una sola oferta. La escalera "200/1.000/2.500" es un grave error. |
| 60:12 | **Escalera de valor**: ejemplo de agencia inmobiliaria con escalones de USD 300 / 1.000 / 2.500. Solo sirve para validar al inicio en DFY. |
| 61:37 | Caso de cliente: agencia inmobiliaria de USD 4.000 con servicio único más una capa de consultoría (cebolla). |
| 62:03 | **Oferta cebolla**: capas de acceso (grupal, + chat 1:1, + llamada 1:1). Acorta la latencia problema-solución. SYK la usó para llegar a 250k/mes. Solo con más de USD 20-30k/mes. |
| 64:33 | **Oferta única**: 120k/mes con una sola oferta de USD 2.500. Charlie Morgan: USD 1.600 con garantía de 20 clientes o 20k en 6 meses. |
| 66:17 | Downsell u otra oferta = "objeto brillante": el problema es tu oferta. Sin 20 ventas por mes no hay cebolla. |
| 66:56 | Conclusión: escalera solo al inicio en DFY; cebolla en coaching con más de 30k; única para empezar y hasta más de 15k/mes. |
| 68:33 | **Oferta espejo**: refleja necesidades, metas e intereses del cliente ("es exactamente lo que necesito", la analogía del espejo del probador). |
| 69:11 | 4 características: vende resultados, refleja metas e incentivos, es tangible y enfocada, y es operativamente viable. |
| 70:19 | Incentivos desalineados: 10 videos por USD 1.000 vs. el mismo precio garantizando 1.000 suscriptores. |
| 71:08 | Ejemplo: 10k/mes en 3 meses con devolución o trabajo hasta lograrlo. Las garantías "10 clientes o tu dinero" están quemadas: buscar otra reversión de riesgo. |
| 72:44 | **Filosofía de precios** (Hormozi): 1) desajuste precio-valor, con el "punto de cancelación" si el valor cae debajo del precio. |
| 73:46 | Mejorar el desajuste: bajar el precio (malo) o subir el valor (bueno, hasta el infinito). |
| 74:23 | 2) Ciclo vicioso: copiar el precio promedio de la competencia y bajarlo. Subir el precio sube la confianza, la convicción del equipo y la inversión emocional. |
| 74:50 | Tope de elasticidad por nicho (seducción: USD 1.000 ya es high ticket). |
| 76:00 | 3) Precio alto = valor alto. Ejemplo: USD 16k contra competidores de 5k. |
| 76:54 | Experimento: ¿qué harías si cobraras 10x? Subir precio solo con 10-20 clientes por mes. |
| 77:38 | **Arte de resonar** (analogía del petróleo de Charlie Morgan): bolsas de presión en la mente; se perforan con palabras. |
| 78:29 | **Condiciones latentes**: fuerzas psicológicas, situacionales y cognitivas que el mercado comparte. |
| 79:22 | Ejemplo de condiciones latentes del coach/consultor principiante: compró un curso de USD 500, síndrome del impostor, procrastina con la web, culpa al nicho, 10k en un pedestal, empezó por enojo. |
| 80:30 | Analogía de la radio: la oferta sintoniza la frecuencia (la condición latente) y "la música comienza a sonar". |
| 81:18 | Ejemplo: "10k es solo la primera fase", "con 2 h por día de contenido". De acá salen los ángulos de comunicación. |
| 82:17 | **Tarea**: listar 5 condiciones latentes de tu mercado. |
| 82:34 | Nota final para cuando te rechacen: ¿comprarías vos tu oferta? Hacela tangible, simple, orientada a resultado y sobre un problema doloroso. |
| 83:10 | Diagrama de la brecha: situación actual, escalera (metodología), tiempo, situación deseada, estrella/norte (el impulso), pilares del paso a paso y trampolín (la reversión de riesgo). |
| 84:19 | Cierre: sigue la L7 práctica (crear la oferta) y la tríada adquisitiva. |
