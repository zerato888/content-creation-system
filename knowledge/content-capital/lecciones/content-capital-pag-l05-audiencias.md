## En una línea

Cuatro tipos de audiencia (básicas, personalizadas, similares, por intereses) ordenadas en una **planilla por temperatura y etapa**: frío/TOFU (broad, detailed targeting, lookalikes), tibio/MOFU (visitantes web, reproducciones de video, engagement) y caliente/BOFU (carrito o agendados, compradores, lista de clientes). Incluye cómo crearlas, la nomenclatura (BROAD AUTOMATIC, WV 180D, LAA 1 %) y la regla de que **el anuncio segmenta más que el conjunto**. Instructor: **Nicolás Donovan** (00:00).

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:00 | Qué son las audiencias y cómo se crean. Presenta una planilla propia de públicos. |
| 00:40 | Audiencia = grupo definido por características, intereses y comportamientos. Mostrar a un público calificado aumenta la probabilidad de venta. |
| 01:53 | **Básicas**: edad, género, ubicación, idioma. Segmentación "totalmente fría", buena para testear creativos. |
| 02:14 | "Últimamente en Meta estamos segmentando a través del anuncio." El anuncio pesa más que la estructura del conjunto. |
| 02:37 | Podés armar un conjunto con miles de intereses y no vender: el problema es el creativo. |
| 02:57 | **Personalizadas**: datos propios (mails, teléfonos, IDs). Orígenes: web/píxel (Tiendanube, Shopify, landings), Instagram, Facebook, videos, base de datos importada. |
| 04:22 | Ejemplo: quienes dieron like a una publicación en los últimos 180 días. Ya conocen el negocio = público tibio. |
| 05:13 | **Similares**: el algoritmo busca gente parecida a una audiencia base. Más amplia pero calificada, según qué tan bien alimentado esté el píxel. |
| 06:35 | **Por intereses**: deportes, viajes, cine, cargos, empresas de más de 200 empleados. "Es cuestión de creatividad." |
| 07:13 | En el conjunto de intereses es donde más hay que sentarse a pensar. Regla: **máximo 10 intereses por conjunto** (mezclando intereses, comportamientos, demográficos y cargos). |
| 07:48 | Muestra la planilla "Plantilla de Públicos, Etapas y Temperaturas". Pensada para e-commerce, sirve para todo. |
| 08:27 | Básicos = broad y detailed targeting (intereses): lo más frío. Se tratan como públicos que no te conocen. |
| 09:17 | **Broad Automatic**: solo datos demográficos, Facebook + Instagram. **Broad Facebook** y **Broad Instagram**: una plataforma cada uno. |
| 09:59 | Detailed targeting: dejar ambas plataformas, salvo que un test ya haya definido la ganadora. |
| 10:20 | Los broad separados sirven para encontrar la **plataforma ganadora**. |
| 10:28 | Testear Facebook aunque parezca obvio que no: la competencia bajó porque todos migraron a Instagram. Al menos 2-3 días. |
| 10:52 | "Testeen con el mínimo": equivocarse rápido y barato. Si no, no vas a poder sostener el presupuesto dos meses. |
| 11:10 | **Similares (LAA, lookalike audience)** salen de un personalizado: engagement de Instagram o Facebook, reproducciones de video. |
| 12:02 | Si un reel se viralizó **por valor** (no por ser solo dinámico) y trajo público calificado, crear un público con sus reproducciones (3 s, 25/50/75/95 %) para retargeting o lookalike. |
| 12:59 | LAA de visitantes web, agregados al carrito, registrados o agendados, compradores. Elegir con criterio el evento de origen. |
| 13:58 | ¿Por qué los similares son fríos? No te conocen. El broad apunta a gente que scrollea: con buen anuncio "pega mucho" y es muy rentable. |
| 14:53 | **Personalizados** en dos grupos: tibios y calientes. Tibios: cumplieron cierto evento (reproducción de video, visitante web). |
| 15:20 | El visitante web solo entró: puede ser un clic sin querer o curiosidad. Por eso es tibio. |
| 15:57 | Hay que llevar a la web tráfico calificado; si mandás todo broad, el retargeting después no sirve. |
| 16:19 | Recomienda lanzar tráfico (web, formulario, interacción en Instagram) con públicos por intereses y similares (IG engagement, visitantes web). |
| 16:49 | Engagement de Instagram y Facebook = tibios. |
| 17:05 | Para servicios: evento personalizado del píxel de "personas que agendaron" (nombre sugerido: clientes potenciales), en lugar de agregados al carrito. |
| 18:00 | **Calientes**: agendados o carrito, compradores (recurrentes, con descuento para e-commerce), lista de clientes = públicos fieles. |
| 18:54 | **TOFU** = frío, reconocimiento. **MOFU** = tibio, consideración (compara con la competencia). **BOFU** = caliente, decisión. |
| 19:47 | Contenido para MOFU: demostraciones, mostrar el proceso, el equipo, el sistema; en servicios, cómo se va del punto A al punto B. |
| 20:24 | BOFU: le falta "un empujoncito", ofertas exclusivas; se puede ser más agresivo sin saturar. |
| 20:44 | Teoría de frecuencia: TOFU 1 vez, MOFU 3-6 veces, BOFU 6-10 veces. |
| 21:06 | En la práctica, TOFU "funciona muchísimo", MOFU es sobre todo un filtro y BOFU vende si reducís la barrera de entrada. |
| 21:42 | Demo en el Administrador de anuncios (tres rayitas → Públicos). Pide el código de autenticación de dos pasos. |
| 23:37 | De nuevo: evitar Meta Business Suite. |
| 24:31 | Crear públicos guardados para un caso: hombres de 24-40 en Argentina. **BROAD AUTOMATIC**, **BROAD FACEBOOK**, **BROAD INSTAGRAM**. Público original, Advantage desactivado. |
| 26:19 | Usarlos: campaña de tráfico manual "TRÁFICO – 30/10", Advantage desactivado. |
| 27:10 | **La nomenclatura va en el conjunto** = nombre del público + fecha ("BROAD AUTOMATIC – 30/10"). Así se sabe qué público corre sin abrir el conjunto. |
| 28:10 | Usar público guardado: carga los datos demográficos. |
| 29:05 | Orden visual clave cuando tenés 10-15 clientes, para reportes y para controlar al trafficker. |
| 29:50 | Ubicaciones manuales. En tráfico al perfil de Instagram: desactivar Audience Network. En clientes potenciales también: "está lleno de bots". |
| 31:13 | Duplicar el conjunto para BROAD INSTAGRAM (solo IG) y BROAD FACEBOOK (solo FB): mismo anuncio y mismo público en distintas ubicaciones. |
| 32:12 | Sirve para optimizar: en qué plataforma, público, creativo o video está la conversión. |
| 32:54 | **Detailed targeting**: se crea duplicando el conjunto en la campaña. Nombre "DETAILED TARGETING (fecha)", opcional "HI TICKET". |
| 34:11 | Ejemplo fitness: intereses salud y bienestar, calidad de vida, hábitos saludables, gimnasio. |
| 35:19 | "**Definir mejor**": intersección de intereses (gimnasio) Y cargo (dueño). |
| 36:05 | Tamaño estimado: apuntar a unos 2-4 millones, sin obsesionarse; 4-6 millones está bien. |
| 36:37 | En detailed targeting activa ambas plataformas si todavía no hay ganadora. |
| 37:10 | **Lookalikes** requieren primero un personalizado y un píxel alimentado. |
| 37:47 | Crear público personalizado → orígenes (video, web/píxel, Instagram, Facebook, lista). Sitio web → píxel → "Todos los visitantes del sitio web" (PageView). |
| 38:48 | Retención máxima del píxel: **180 días**. Nombre: "WV 180D" (website visitors, 180 días). |
| 39:48 | "Crear público similar" → país → **1 %**. Luego otro al **3 %**. |
| 40:48 | Más cerca del 0 % = más chico y más parecido al origen; más alto = más grande y menos calificado. Él juega entre 1 % y 3 %. |
| 41:43 | Cargar los públicos en la campaña: duplicar el conjunto y ponerle el nombre del público ("LAA 1% WV 180D"). |
| 44:47 | Con público original: agregar el similar o el personalizado desde el buscador de públicos. |
| 45:16 | Para el personalizado: duplicar y dejar solo "WV 180D". Para el 3 %: duplicar y cambiar. |
| 46:44 | Cierre: usar la planilla con sus filtros por temperatura y experimentar. |

## Tareas y herramientas

- Descargar y usar la planilla de públicos por temperatura.
- Crear los públicos guardados (3 broad), un detailed targeting de hasta 10 intereses, personalizados del píxel (WV 180D) y lookalikes al 1 % y 3 %.
- Nombrar cada conjunto con el público + fecha y duplicar conjuntos para testear plataforma y público.
- Herramientas: Administrador de anuncios → Públicos, Google Sheets.
