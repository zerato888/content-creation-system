## En una línea

El "modelo SYK" es vender conocimiento empaquetado por dos caminos: el tuyo (DWY/DIY) o el de otro experto asociándote por un 15-50%. El negocio se divide en conocimiento + sistemas, y se escala con una oferta mínima viable (5-10 cupos baratos), venta diaria con subas de precio de 5-10%, delegación y la "triple C" (curso, coaching, comunidad).

| 10:20 | Camino 2: vendé el conocimiento de OTRO, como una agencia pero a porcentaje: embudos, contenido y ofertas para expertos. |
| 11:30 | Recomienda empezar a porcentaje del dinero generado. Excepción: inmobiliario, donde conviene un retainer de 2-5k USD por 3-4 meses adelantado. |
| 12:10 | **Dos patas: conocimiento y sistemas.** Conocimiento = habilidad que aporta valor suficiente para venderse por miles. Sistemas = marketing, ventas, operaciones y servicio. |
| 12:55 | **Escenario 1**: tenés conocimiento y tiempo. Negocio unipersonal hasta ~10k/mes con un setter y un closer; después asistente operativo y CSM. Dice tener clientes solos a 100k/mes (anécdota). |
| 13:40 | **Escenario 2**: tenés conocimiento pero no tiempo. Buscás un socio (growth partner) por 15-50% que maneje la operación; vos hacés contenido y servicio. |
| 14:15 | **Escenario 3**: no tenés conocimiento pero sí sistemas. Te asociás con un experto por 15-50%. |
| 14:35 | Rentabilidad: con todo propio, márgenes muy altos (dice "85%") pero todo depende de vos. |
| 15:00 | Cómo elegir al experto: facturación actual, seguidores, alcance, tráfico, proyección y compromiso. Ejemplo: para llevarte 10k al 25%, el negocio tiene que hacer ~40k (y el % suele ser sobre profit). |
| 15:45 | Con este formato, 1 a 3 clientes como máximo; lo ideal es uno al 50% y "hacerse ricos juntos". |
| 16:30 | **4 áreas del negocio digital** para repartir porcentajes: marketing (ojos), ventas (conversión), servicio (transformación A→B), operaciones (CRM, métricas, contratos, finanzas). ~25% cada una como supuesto. |
| 17:00 | Ejemplos de reparto: 50/50 si cada uno lleva dos áreas; 35% si llevás ventas + algo de marketing (25+10). Todo por contrato: quién hace qué, qué porcentaje y qué resultados. |
| 17:50 | "Esto no es solo subir historias": es un negocio real. Cifras propias y de amigos (300k/mes; 3-5M/mes) como anécdota. |
| 18:40 | **Oferta mínima viable**: vendés 5-10 cupos iniciales baratos, validás precio, oferta y sistema, entregás 1:1 y después creás un producto grabado. |
| 19:20 | Precio inicial fácil de comprar (300-1.000 USD por 3 meses, como ejemplo). El producto: módulos grabados, respuestas a preguntas frecuentes, recursos rellenables (ej. calculadora de profit), accionables claros. |
| 19:40 | **Sistema que venda todos los días**: precio inicial y objetivo mensual (10 cupos a 500 = 5k; luego 15 = 7,5k) y subas a 750, 900, 1.000. |
| 20:00 | Subas de 5-10% cada vez, usadas como "why now" en redes. |
| 20:10 | Sistematizar la entrega: grabar lo que siempre explicás, pasar de 1:1 a grupales, delegar partes del servicio en expertos (nutrición, anuncios, producto). |
| 20:50 | Una llamada semanal por cada área de problema (anuncios, prospección, contenido, ventas, servicio), como hacen en SYK. |
| 21:15 | Ejemplo coach fitness: 1:1 con 15 clientes → nutricionista → grabar teoría → grupales → entrenador. 30 clientes a 1.000 = 30k; con nutricionista, entrenador, setter y closer quedan ~20k netos (números ilustrativos). |
| 22:30 | **Paso a paso**: 1) validar la oferta con 5 cupos (baratos salvo que la oferta genere dinero o tengas mucha autoridad). "Tienen que regalarse al inicio." |
| 23:10 | 2) Vender "evergreen" todos los días: 15 ventas/mes → 20, 25, 30, subiendo precio. 3) Delegar al llegar al máximo (expertos, CSM para onboarding y seguimiento). |
| 23:50 | 4) **Triple C**: curso (módulos grabados), coaching (1:1 o grupal) y comunidad (grupo privado). Así se llega a ~30k/mes, incluso solo con reels e historias. |
| 24:20 | La economía del conocimiento en Latinoamérica "va a ser una explosión" (opinión). |
| 24:40 | **Disclaimer**: si vas a porcentaje con un experto, que esté comprometido y tenga algo validado; arrancar de cero los dos con un desconocido es muy difícil. |
| 25:20 | Ejemplos públicos de quienes vendieron su método (Hormozi, Cardone, Gadzhi, entre otros). "No es una moda, es una tendencia irreversible." |
| 25:55 | Regla: nadie aprende de alguien sin resultados. Primero dominar una habilidad y un mercado, después empaquetar y vender. |
| 26:30 | Cierre: SYK como "vehículo" para el objetivo de ingresos que tengas. |
