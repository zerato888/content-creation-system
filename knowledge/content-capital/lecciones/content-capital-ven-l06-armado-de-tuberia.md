## En una línea

El negocio se mira como **una sola tubería** (mercado → canilla de adquisición → conversación → setting → pre-call → llamada → servicio → recompra). Cada tramo tiene un dueño, una métrica fundamental y una lista de cuellos de botella posibles. Siempre va a haber un cuello de botella: lo que importa es **elegir dónde** tenerlo, y cuidar la **métrica clave** (tasa de cierre calificada).

Instructor: se presenta como "Mati Molina" (00:00).

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:00 | Presentación. Objetivo: "descomprimir" el negocio para ver dónde están los cuellos de botella. Siempre va a haber uno; lo importante es elegir dónde. |
| 01:02 | Ejemplo: con mucho flujo de leads la tasa de calificación puede caer bajo el KPI (35%, según él) y no pasa nada si el resto cumple. Clase práctica. |
| 02:00 | No le gusta separar el negocio en "embudo de ventas" y "embudo de fulfilment": todo está conectado. El barril gigante = el mercado, el valor bruto de leads. |
| 03:04 | El mercado es prácticamente infinito. La canilla = el método de adquisición (contenido orgánico en el ejemplo, también anuncios o prospección en frío). |
| 04:03 | Tres formas de llamar la atención de desconocidos. El agua que fluye son los leads, que él llama "conversaciones". |
| 05:00 | Entrada típica: pieza de contenido → CTA → automatización de ManyChat. Con hand raiser se decide si dar o no el recurso. |
| 06:01 | Con CTA directo o micro lanzamiento puede no haber ManyChat y entrar directo el setter. Tramo verde = marketing; métrica: cantidad de conversaciones. Mínimo 20 por día. |
| 07:00 | Ideal 50-100 por día; con 200.000 USD/mes, 6.000-8.000 conversaciones mensuales (anécdota). Cuellos de botella de marketing: estrategia de comunicación, calidad del contenido, hook. |
| 08:04 | Más cuellos: idea del contenido, CTA. Entra la etapa de prospección y setting. |
| 09:02 | Estructura de prospección: situación, dolores, trabas, objetivos, intentos previos → Calendly. Seguimientos: hasta 5 si ya se envió el Calendly, hasta 2 si no. Métrica: tasa de agenda. |
| 10:01 | Con 100 conversaciones diarias, 2-4 agendas por día. Cuellos: marketing (leads descalificados) o, lo más común, la estructura de prospección. |
| 11:00 | Ventas empieza con la confirmación por WhatsApp (Business): video o mensaje, preguntar por qué agendó. Mantener la charla hasta 1-2 h antes. Recordatorios el día de la llamada. |
| 12:01 | Todo eso es el pre-call para lograr el show. En la llamada: apertura, marco, descubrimiento, calificación, presentación, preguntas, objeciones, negociación y pago. |
| 13:00 | En cada paso de la llamada se pierde confianza. Métrica 1: tasa de cierre calificada, mínimo 20-30% según él. Cuello: la oferta. |
| 14:02 | Otros cuellos: guion de ventas y habilidad del closer (uno cierra 20%, otro 60%). Meta del dueño: depender menos del closer. Métrica 2: show up. |
| 15:00 | Negocios de 10-20k/mes con show up de 30-40% (anécdota). Cuellos del show up: prospección que no vende el valor de la llamada, o pre-call que no confirma. |
| 16:01 | Si hay equipo, lo primero es tarea del setter y lo segundo del closer. Otras métricas: AOV trato cerrado (ejemplo 2.000 o 2×1.000 → promedio ~1.200) y AOV día 1. |
| 17:01 | % cash collected por venta: ticket 2.000, cobrado 1.000 al entrar = 50%. Entrega del servicio de ellos: contrato, onboarding, Discord/Skool, módulos, Génesis, Nirvana. |
| 18:01 | Auditoría, fundaciones, adquisición, ventas; primeras victorias, entrevista de caso de éxito, upsell/resell o no se pide la garantía → profit. Riesgo: reembolsos altos (expectativas, servicio o "clientes pesadilla"). |
| 19:03 | Poco resell/upsell: faltan resultados, falta la oferta siguiente (de 10k a 30k) o falta seguimiento al final. Mirada "láser" de dueño de negocio. |
| 20:00 | Tubería general: leads → adquisición (tasa de agenda, calificación, show up) → conversión (tasa de cierre) → servicio (reembolso), con upsell que vuelve a conversión. |
| 21:01 | Tubería descomprimida de atracción: contenido (reels/historias en Instagram) → ej. 3.000 leads/mes → respuestas → agendas → agendas presentadas y calificadas. |
| 22:02 | Conversión: descubrimiento → presentación → objeciones → cierre. Servicio: onboarding → auditoría → soporte → resultado → profit. |
| 23:00 | Tubería de conversión con input (bomba de leads) y tuberías A-D. A: tasa de agenda 5%, sana (KPI > 4%). B: calificación 80%, sana. |
| 24:02 | C: show up 50%, defectuosa. D: cierre calificado bajo KPI (ejemplo 15%). Aguas arriba se ven las consecuencias; aguas abajo se buscan las causas. |
| 25:00 | Causa del cierre bajo: show up bajo, closer u oferta. La "llave con piedra" = key metric: si la tasa de cierre calificada está en KPI, el resto puede estar fuera. |
| 26:00 | Con 65% de calificación y el cierre en KPI, está todo bien: un cuello de botella "a propósito". Los leads se van perdiendo en cada tramo. |
| 27:03 | Objetivo: que la mayor cantidad pase de la entrada al final. Nunca se termina. Ejemplo de elegir: más casos de éxito (mejorar el servicio) o más ingreso (250k → 500k). |
| 28:02 | Cada objetivo pide ajustar la tubería. Métricas clave: tasa de cierre calificada, o tasa de reembolso en la entrega. Cierre. |
