## En una línea

Plantilla de presentación para la **kick-off call** de un servicio hecho por vos (DFY): bienvenida con prueba social → quién es tu gestor de cuenta (CSM) → sobre la agencia → equipo → casos → cómo funciona el sistema → cómo el cliente maximiza resultados → expectativas y cronograma → cosas para recordar → plan de acción → herramientas → próximos pasos. Es base, no para copiar: tiene que ser profesional, dar norte y claridad y dejar accionables.

Instructor: **no identificado**, el mismo de L2-L7 ("acá Fede", CDN; inferencia). Anuncia otro video, con otra persona, sobre la kick-off del modelo hecho con vos (DWY) (00:27; el nombre sale deformado).

## Recorrido de la clase

| Min | Idea |
|---|---|
| 00:16 | Presenta un template para usar de base, "no quiero que copien y peguen". Esta es la versión DFY; la DWY viene en otro video. |
| 00:43 | **Hoja 1, bienvenida**: saludo y debajo la oferta resumida con prueba social (ej.: cantidad de dueños de negocio ayudados). Hecho rápido; hay que trabajarlo. |
| 01:32 | **Hoja 2, el CSM o community manager**: foto, experiencia, valor que aporta, responsabilidad, teléfono o usuario de Discord, datos extra útiles. |
| 02:07 | **Hoja 3, sobre nosotros**: tiempo en el negocio, experiencia, qué hicieron, diferencia con la competencia, objetivo para este cliente, misión (con el mundo, con el nicho). "Muy personal." |
| 02:35 | **Equipo**: nombre y rol. Pone cinco lugares como ejemplo; si sos vos solo o son dos, ponés eso. |
| 02:53 | **Resultados recientes o casos de estudio**, idealmente del mismo tipo de negocio que el cliente (ej.: agencia de turismo con anuncios). |
| 03:14 | **Cómo funciona tu sistema**: el servicio desglosado, como en adquisición de clientes. Muestra un documento propio que explica el servicio en 4-5 párrafos para que se entienda de una. |
| 04:13 | **Cómo maximizar tus resultados como cliente**: lo que tiene que hacer él (ver módulos, conectarse al 70% de los vivos, pedir feedback semanal, mandar llamadas para analizar, completar el formulario de entrada). |
| 04:44 | **Resultados y expectativas claras**: qué esperar, en cuánto tiempo y cómo, en forma de cronograma. No será exacto; su función es dar tranquilidad y claridad. |
| 05:27 | **Cosas importantes a recordar**: puntos que quedan claros desde el día uno (ej.: usar el entrenamiento de ventas, usar el sistema de reportes, bajar expectativas sobre el resultado). |
| 05:46 | **Plan de acción**: lo que se va a trabajar; se puede ajustar en conjunto en la llamada. |
| 05:57 | **Herramientas y recursos**: Skool, Discord, lo que uses. |
| 06:06 | **Próximos pasos** accionables al salir de la llamada: invitación al Discord de soporte, acceso a Meta Business Suite si hay anuncios, recorrido del módulo de onboarding, llamada de control con el CSM, cómo funciona el sistema de reportes. |
| 06:38 | Cierre: es un ejemplo. Lo que importa es que sea profesional, dé norte y claridad y deje accionables. |
