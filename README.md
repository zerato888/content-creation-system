# content-creation-system

> **v0.1 en construcción.** Esta rama todavía no se puede instalar. El README final llega con la versión publicada.

Un kit para producir contenido (investigación, guiones, subtítulos, carruseles, planes de b-roll) que se instala **por proyecto** en Claude Code y/o Codex, en Windows o macOS. Trae un núcleo gratuito y módulos opcionales que se habilitan solo cuando pasan su prueba.

**English:** v0.1 is under construction and not installable yet. This is a per-project content-production kit for Claude Code and Codex on Windows and macOS: a free core plus optional modules that become installable only after they pass their tests.
