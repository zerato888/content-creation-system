# Plantillas de salida (opcionales)

El único archivo obligatorio es el `brand.json`. Estas plantillas sirven si además se quiere un
documento de marca para leer.

## Documento de marca

```markdown
# <Marca> — ficha de marca

## Resumen
- Frase: <P1>
- Público: <P2>
- Emoción: <P3>
- Diferencia: <P4>
- Éxito: <P5>

## Pilares
1. <P15> — <una línea>

## Reglas de contenido
- Formatos: <P16>
- Plataformas: <P17>
- Nunca: <P18>

## Personalidad
<P11: tres adjetivos con una línea cada uno>
```

## Guía de voz

```markdown
# <Marca> — voz

- Tono por defecto: <P12>
- Siempre: <P13>
- Nunca: <P14>
- Largo de frase: corto / medio / largo

Así suena: "<frase de ejemplo>"
Así no suena: "<frase que rompe la voz>"
```
