# wiki-memory-system

Build a personal knowledge base and a persistent lessons log — no API
keys, no external services, just structured markdown files.

## Setup

None — this skill works on local files from first use.

## Usage

```
/wiki-memory-system
```

Start with `init`, then use `ingest` as you learn things and `query` to
retrieve them later. See `../../shared/wiki-engine/SCHEMA.md` for the
full page-format reference.
