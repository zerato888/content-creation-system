# Generic Carousel Template

**Slide structure:**

1. **Cover** — the topic as a bold statement or question. One idea only.
2. **Body slides (3-5)** — one point per slide, each building on the
   last. Avoid restating the cover slide's point.
3. **CTA slide** — the one action from the brief (follow, comment,
   visit link). If no CTA was given, default to a soft engagement prompt
   ("Which of these resonates most?").

**Copy guidance:** each slide's text should be readable in under 3
seconds. If a slide needs more than ~15 words to land, split it into two
slides.
