# News Carousel Template

**Slide structure:**

1. **Headline slide** — the core fact, stated plainly, no editorializing.
2. **Context slide** — why this matters / what led here.
3. **Detail slides (2-3)** — the specifics, one facet per slide.
4. **"What this means" slide** — the implication or takeaway for the
   target audience specifically (not a generic summary).

**Copy guidance:** lead with the fact, not your opinion of the fact.
Save interpretation for the final slide, and label it as interpretation.
