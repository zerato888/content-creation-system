# Educational Carousel Template

**Slide structure:**

1. **Hook slide** — state the promise ("5 ways to X", "How to Y without
   Z"). This is the reason someone stops scrolling.
2. **Numbered steps/tips (one per slide)** — each slide covers exactly
   one step. Number visibly (1/5, 2/5, etc.) so the viewer tracks
   progress.
3. **Recap slide** — restate all steps in condensed form (useful for
   screenshotting/saving).
4. **CTA slide** — drive toward the brief's action, or default to
   "save this for later".

**Copy guidance:** each step slide should be actionable, not just
descriptive — "do X" beats "X is important".
