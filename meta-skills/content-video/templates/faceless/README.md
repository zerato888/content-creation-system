# Faceless Video Template

**Structure:** Same hook → tension → payoff arc as any script, but no
on-camera talent — 100% voiceover + generated/stock visuals or motion
graphics. Works for any duration from short-form (30-60s) to long-form
(5-10min).

**Visual strategy:** since there's no face to anchor attention, visual
variety and pacing matter more — avoid static single-image holds longer
than 4-5 seconds without motion or a cut.
