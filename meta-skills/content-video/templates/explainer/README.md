# Explainer Template

**Structure:** Hook (the question/confusion) → 3-5 explanation beats,
each building on the last → recap → CTA. Default duration: 60-120s.
Voiceover-driven; visuals (b-roll, motion graphics, diagrams) support the
narration rather than lead it.

**Pacing:** slower than short-form-reel — one idea can hold the screen
for 5-10 seconds if the voiceover is still explaining it.
