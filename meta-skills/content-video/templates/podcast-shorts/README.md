# Podcast Shorts Template

**Structure:** Extract a single self-contained moment (30-90s) from
longer source material — a moment that makes sense without the
surrounding context. Reframe to vertical, add burned-in captions,
optionally add a text overlay naming the guest/topic in the first 2
seconds.

**Selection criteria:** the clip should have its own hook (a strong
opening line within the extracted range) — don't just cut at fixed
intervals.
