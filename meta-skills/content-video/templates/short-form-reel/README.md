# Short-Form Reel Template

**Structure:** Hook (0-3s) → 2-4 body beats → payoff/CTA (last 2-3s).
Default duration: 30-60s. Vertical (9:16).

**Pacing:** cut or change visual every 2-4 seconds to sustain attention —
faceless/explainer routes can run longer per-shot if the voiceover is
carrying the pacing instead.
