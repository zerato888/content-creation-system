# agents-orchestration

Coordinates multiple meta-skills and agents for multi-step content
projects. Use this when a brief spans more than one piece of content —
for a single carousel or video, use that meta-skill directly.

## Setup

None of its own — downstream meta-skills' key requirements apply as they
get invoked.

## Usage

```
/agents-orchestration
```

See `SKILL.md` for the kickoff flow.
