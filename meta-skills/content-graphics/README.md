# content-graphics

Generate thumbnails, quote cards, tweet-style posts, or motion graphics.

## Setup

```bash
cp .env.example .env
# add MAGNIFIC_KEY (required), HIGGSFIELD_KEY (optional fallback)
../../setup-env.sh .env MAGNIFIC_KEY
```

## Usage

```
/content-graphics
```

See `SKILL.md` for routes, `templates/` for composition guidance per type.
